## Measurement rules

Do not compare a newly published page against a period before it existed without noting the limitation.

Use Search Console exports where practical. Search Console may omit anonymized queries and has table-row/data aggregation limitations, so exported totals and UI totals can differ.

## First optimization queue

After baseline capture, prioritize:
1. High-impression / low-CTR queries.
2. Pages receiving impressions for relevant non-branded queries but few clicks.
3. Queries where the wrong landing page is appearing.
4. Pages with impressions but weak engagement.
5. Countries showing meaningful organic demand.
